# Armstrong Number Checker (C Program)

## 📌 Description
This is a simple C program that checks whether a given number is an **Armstrong number** or not.

An Armstrong number is a number whose sum of the digits raised to the power of the number of digits is equal to the number itself.

## 🛠️ Technologies Used
- C Programming Language
- GCC Compiler
